# @dankest-llc/xchain-connect

The reference client and request and return codecs for XChain wallet requests and Login with XChain provide shape validation only and have zero runtime dependencies.

```sh
npm install @dankest-llc/xchain-connect
```

The package includes three builds:

- ESM: `dist/xchain-connect.js`
- CommonJS: `dist/xchain-connect.cjs`
- IIFE: `dist/xchain-connect.min.js`, exposed as the global `XChainConnect`

The package also bundles `wallet-requests.json`.
